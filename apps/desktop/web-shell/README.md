# 织流桌面网页壳

该入口在 Electron 中直接加载 `https://dev.echoai.best/enterprise`，复用网页企业版的登录、工作台、会话、企业资源、配额和模型能力。

- 通过 `skin.css` 和 `skin.js` 在工作台注入独立的“织流企业 AI 工作台”视觉，不替换底层 React 功能。
- 顶部品牌栏、左侧工作台导航、项目会话卡片和中央创作台采用独立的布局与配色。
- 页面只允许在企业云域名内导航，外部链接交由系统浏览器打开。
- 登录状态保存在独立的持久化 Electron 会话中。
- 原始本地 Harness 入口保留为 `Launch-Harness.ps1`。

皮肤固定使用浅色外观，侧栏渐变和 Markdown 代码背景使用同一组浅色变量。右侧面板的外层及 DockKit surface 必须保持透明，背景由实际打开的面板绘制，避免关闭后遮挡会话。输入框只设置基础文字颜色，角色、指令和文件引用标签保留各自的语义颜色，悬停与选中状态使用浅蓝底色。修改皮肤后重启桌面壳，并检查已有会话、新会话、引用标签的悬停与选中、窄窗口以及侧栏展开和收起状态。
