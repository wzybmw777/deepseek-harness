# 智能体中心 Bundle

企业控制台负责产品存储、计费与租户策略。此 Bundle 负责另外两件事：每个租户渲染的工作台界面，以及这些界面呈现的第一方目录。

## 界面

`cordis.patch.yml` 以稳定标识 `enterprise-resources-ui` 插入 `@deepseek-ai/dsh-client-ui-enterprise-resources`。租户启动不再硬编码该包的路径；是否插入由企业插件策略决定。

## 目录种子

`catalog/agents.json` 列出第一方智能体，包含适用任务、所需材料、交付内容、使用示例与提示词。控制台打开产品存储时，会把文件内容哈希与上次种入记录的哈希比较。变化时把存储中尚不存在的目录标识以草稿形式插入，并记录新哈希。管理员编辑或删除过的条目不会被改写。

## 失败行为

目录文件缺失或格式错误时，控制台不会产生任何模型可见输出，只是继续使用存储中已有的内容；种入过程不会阻塞启动。
